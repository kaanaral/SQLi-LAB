Expected payload

This test sends a specific payload. If it's been changed in test_sqli.py, the original was:

Hello' AND (SELECT SUBSTR(password,1,1) FROM credentials WHERE username = 'Hello') = 'H' --

Good to know

One request only answers one yes/no question — real attacks repeat this to read data a character at a time.
Unlike UNION-based injection, nothing is ever displayed directly — only the true/false pattern leaks anything.
If the server ever returns raw error messages here too, that's a second, separate leak worth closing.
